## 💡 Sobre el Proyecto

Stellaris es un proyecto web que consiste en una e-commerce ficticia, este proyecto fue en conjunto con una compañera de Davante;
se encargo de la imagen y marketing de la tienda y yo del desarrollo web de esta misma. 
Este proyecto fue desarrollado desde cero, sin frameworks, lo que me permitió afianzar las bases del desarrollo Frontend.
He utilizado apoyo de Gemini y Claude para los apartados que se me dificultaban.  

### ✨ Características Principales
- **Interfaz Responsiva:** Adaptable a diferentes tamaños de pantalla (móvil, tablet, escritorio).
- **Interactividad:** Lógica implementada con Vanilla JavaScript (sin librerías externas).
- **Maquetación:** Uso de CSS Flexbox / Grid para la estructura visual.
- **Manipulación del DOM:** Cambios dinámicos en la interfaz según las acciones del usuario.
